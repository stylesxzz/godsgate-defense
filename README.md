## 🌐 Visão Geral do Sistema

O **God's Gate** é uma solução de cibersegurança de alta performance projetada para oferecer visibilidade total, detecção rápida e contenção ativa de ameaças em infraestruturas de TI e endpoints distribuídos. 

Construído sobre uma arquitetura reativa de baixa latência via WebSockets e FastAPI, o sistema combina coleta contínua de telemetria, análise de vetores de ataque e uma interface visual otimizada para operadores SOC (Security Operations Center).

## 🏗️ Arquitetura e Funcionamento Operacional

```text
[ Endpoints / Ativos ] ──( Telemetria Encriptada )──> [ GodsGate Engine ]
                                                             │
                                     ┌───────────────────────┴───────────────────────┐
                                     ▼                                               ▼
                         [ Banco de Dados Persistente ]               [ Dashboard SOC / WebSocket ]

1. Coleta de Telemetria (Agentes de Ponta)
​Agentes instalados nos ativos de rede monitoram eventos críticos em segundo plano:
​NETWORK_IPS: Análise de tráfego, detecção de varredura de portas (port scanning), anomalias de rede e tentativas de intrusão.
​ENDPOINT_FILE: Integridade de arquivos do sistema, detecção de alterações não autorizadas e processos suspeitos.
​SYS_LOGS: Telemetria de status operacional do dispositivo e conexões ativas.
​2. Painel de Controle Integrado
​Uma central de comando web fornece métricas consolidadas em tempo real:
​Total de eventos registrados e categorizados.
​Contagem dinâmica de agentes ativos/online.
​Identificação automática da principal categoria de ameaça (Top Category).
​Logs detalhados com carimbo de data/hora, origem do ataque e ação corretiva aplicada.
